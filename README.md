# YCD OIL ERP & Operations

نظام إدارة وتشغيل **شركة وجهتك الإبداعية لزيوت وخدمات السيارات**.

## المرحلة الحالية
الفرع `codex/v1-foundation` يحتوي على الأساس الحقيقي للنسخة الأولى:
- Next.js + TypeScript بواجهة عربية RTL.
- PostgreSQL + Prisma.
- الفروع والأقسام والمستخدمون والأدوار والصلاحيات.
- العملاء والمركبات وأوامر الخدمة.
- المنتجات وحركات المخزون.
- الفواتير والمدفوعات وضريبة القيمة المضافة القابلة للتهيئة.
- سجل المركبة والكوبونات والموافقات وسجل التدقيق Audit Log.
- نواة معاملة إكمال أمر الخدمة داخل Database Transaction مع حماية أولية من التكرار.
- GitHub Actions للتحقق من PostgreSQL وPrisma وSeed وبيانات ما قبل التشغيل وTypeScript والبناء.
- دورة مالية تشمل التمويل من شركات المجموعة، المصروفات، البنوك، مدى، المطابقات والإقفالات.
- حالة PREOPENING تمنع التشغيل التجاري حتى اكتمال متطلبات الإطلاق.

## التشغيل محليًا
1. انسخ `.env.example` إلى `.env`.
2. جهّز PostgreSQL وحدّث `DATABASE_URL`.
3. شغّل `npm install`.
4. شغّل `npm run db:generate`.
5. شغّل `npm run db:migrate`.
6. شغّل `npm run db:seed`.
7. شغّل `npm run dev`.
